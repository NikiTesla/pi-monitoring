# Third-party notices

The application uses `gopkg.in/yaml.v3` v3.0.1. Its MIT and Apache 2.0
attribution and notice are preserved in `third_party/yaml`. The complete Apache
2.0 license text is included there as well. No dependency source is vendored.

Compiled binaries also include the Go runtime and standard library. Go's license
and patent grant are in `third_party/go`. These notices also cover the Go project
code in the standard library's vendored x packages. Review notices again when
updating dependencies or the release toolchain; optional native libraries or new
dependencies can introduce additional obligations.

The project's own license, once selected, applies to project code separately.
